# 경제 뉴스 시세판

네이버 뉴스 API + 구글 뉴스(RSS)를 함께 가져와서 보여주는 대시보드입니다.
카테고리별(국내증시/해외증시/환율/금리/부동산) "업데이트" 버튼을 누르면
그 시점의 최신 뉴스를 불러옵니다.

## 배포 방법 (Vercel)

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. https://vercel.com 에서 New Project → 방금 올린 저장소를 선택합니다.
3. Framework Preset은 "Other"로 두면 됩니다. (Vercel이 `/api` 폴더를 자동으로 서버리스 함수로 인식합니다)
4. **Environment Variables**에 아래 두 개를 추가합니다. (네이버 개발자센터에서 발급받은 값)
   - `NAVER_CLIENT_ID`
   - `NAVER_CLIENT_SECRET`
5. Deploy를 누르면 끝입니다.

## 로컬에서 테스트하려면

```bash
npm install -g vercel
npm install
vercel dev
```

`.env.local` 파일을 만들어 아래처럼 넣어두면 로컬에서도 네이버 API가 동작합니다.

```
NAVER_CLIENT_ID=발급받은값
NAVER_CLIENT_SECRET=발급받은값
```

## 카테고리 추가/삭제

이제 코드를 안 고쳐도 화면에서 바로 카테고리를 추가하거나 삭제할 수 있습니다.

- 오른쪽 위 **"+ 카테고리 추가"** 버튼 → 이름과 검색어 입력 → 추가
- 각 패널 오른쪽 위 **✕** 버튼으로 삭제

추가한 카테고리는 브라우저(localStorage)에 저장되어 있어서, 같은 브라우저로 다시 접속해도 유지됩니다.
(다른 기기/브라우저에서는 안 보여요. 여러 기기에서 똑같이 보이게 하려면 나중에 서버 DB 저장 방식으로 바꿀 수 있습니다.)

## 카테고리별 뉴스 개수

기본 7개(네이버 최대 7 + 구글 최대 7)로 설정되어 있습니다. 바꾸고 싶으면 `api/news.js` 상단의 `RESULT_COUNT` 값을 수정하세요.

## 참고

- 네이버 뉴스는 공식 검색 API를 사용합니다 (건당 무료, 일일 호출 제한 있음).
- 구글 뉴스는 별도 API 키 없이 RSS 피드를 서버(api/news.js)에서 가져와 파싱합니다.
  브라우저에서 직접 호출하면 CORS 때문에 막히므로, 반드시 서버리스 함수를 거치도록 만들었습니다.
