# 경제 뉴스 시세판 (v3 — 네이버 증권 스타일)

코스피·코스닥·S&P500·나스닥·다우존스 지수 카드, 차트, 환율, 뉴스를
네이버페이증권 홈 화면과 비슷한 구성(상단 지수 카드 → 큰 차트 + 오른쪽 실시간 속보 → 하단 헤드라인 박스)으로 보여주는
개인용 경제 대시보드입니다. PWA로 만들어져 있어서 폰 홈 화면에 설치하면 앱처럼 열립니다.

## v2 → v3, 달라진 점

- **디자인 전면 교체**: 어두운 네이비 → 네이버 증권 느낌의 밝은(화이트) 테마
- **지수 카드 + 차트 추가** (`api/indices.js`)
  - 코스피·코스닥: 네이버가 자기 웹페이지에서 쓰는 실시간 공개 JSON을 그대로 가져와요. **지연 없음**, 키/로그인 불필요
  - S&P500·나스닥·다우존스: 야후 파이낸스 공개 API. 키는 필요 없지만 보통 **15~20분 지연**됩니다 — 카드에 "지연" 배지로 항상 표시
  - 카드를 클릭하면 아래 큰 차트가 그 지수로 바뀝니다
  - 차트는 **접속해 있는 동안 2분마다 수집한 실제 값**으로 그려져요 (과거 데이터를 가짜로 채우지 않음). 브라우저를 새로 열면 오늘 날짜 기준으로 다시 쌓입니다 (localStorage에 날짜별 저장)
- **헤드라인 박스 추가**: AI 요약이 아니라, 선택한 카테고리의 최신 기사 중 1등 헤드라인 + 아래 3개를 그대로 보여줘요 (추가 비용 없음)
- **실시간 속보**를 데스크톱에서는 차트 오른쪽 사이드바로, 모바일에서는 차트 아래로 배치
- 환율 티커는 유지하되 보조 정보로 하단에 작게 배치

## 배포 방법 (Vercel)

1. 이 폴더 전체(파일/폴더 구조 그대로, `index.html`이 맨 위에 오도록)를 GitHub 저장소에 올립니다. (기존 저장소에 올리는 경우, 같은 이름의 파일은 자동으로 덮어써지니 먼저 지울 필요 없어요.)
2. https://vercel.com 에서 New Project → 저장소 선택 → Framework Preset은 "Other" 그대로 둡니다.
3. **Environment Variables**에 아래 두 개를 추가합니다. (네이버 개발자센터에서 발급받은 값, 이전과 동일)
   - `NAVER_CLIENT_ID`
   - `NAVER_CLIENT_SECRET`
4. Deploy 클릭.

환율(`api/fx.js`)·지수(`api/indices.js`) API는 별도 키가 필요 없습니다.

## 실시간 랭킹(국내 주식)은 어디서 가져오나요

차트 아래 "실시간 랭킹" 카드는 네이버 증권이 자기 웹/앱에서 쓰는 공개 JSON API(`stock.naver.com/api/...`)를
그대로 가져와서 보여줘요 (`api/ranking.js`). 로그인/키 필요 없고, 코스피+코스닥 전체를 한 번에 랭킹으로 받아와요.
(처음엔 오래된 HTML 페이지를 긁어오는 방식으로 만들었다가, "거래량상위" 주소가 틀려서 404가 났던 걸 이 방식으로 교체했어요.)

이 부분도 네이버가 응답 형식을 바꾸면 깨질 수 있어서, 배포 후 탭을 한두 개 눌러서 숫자가 뜨는지 확인해주시면 좋아요.
안 뜨면 "데이터를 불러오지 못했어요" 같은 문구만 보이고 나머지 기능은 정상 작동해요.

(다음 단계로 미국 주식/국내 ETF 랭킹도 추가할 예정이에요. 이번 국내 주식 랭킹이 잘 되는 거 확인되면 알려주세요.)

## 배포 후 꼭 확인해주세요 (중요)

`api/indices.js`는 제가 실험 환경에서 외부 네트워크 제한 때문에 **실제로 값을 받아오는 것까지는 테스트하지 못했어요**
(코드 구조는 실제로 쓰이고 있는 오픈소스 프로젝트 소스코드를 직접 읽고 만들었지만, 100% 보장은 아니에요).
배포하고 나서 상단 지수 카드에 숫자가 정상적으로 뜨는지 스크린샷으로 한 번만 확인해주시면,
혹시 안 뜨는 지수가 있을 때 바로 고쳐드릴게요. (환율도 지난번처럼 한 번 이런 이슈가 있었어요.)

## 폰에 앱처럼 설치하기

- **안드로이드(크롬)**: 접속하면 하단에 "추가" 배너가 뜹니다. 누르면 바로 설치돼요.
- **아이폰(사파리)**: 공유 버튼(네모+화살표) → "홈 화면에 추가"를 누르면 설치됩니다. (iOS는 자동 배너를 지원하지 않아서, 접속하면 화면에 안내 문구가 떠요)

설치하면 완슐랭처럼 주소창 없이 앱 아이콘으로 바로 열립니다.

## 카테고리 추가/수정/삭제

헤더 오른쪽 **☰** 버튼을 누르면 바텀시트가 열립니다.
- 목록에서 **수정/삭제** 가능
- 아래 입력창에 이름+검색어 넣고 **추가하기**

카테고리는 브라우저(localStorage)에 저장돼서, 같은 기기·같은 브라우저에서는 유지됩니다.
다른 PC/폰에서는 기본 카테고리(국내증시/해외증시/금리/부동산)로 시작하고, 거기서 다시 추가하면 됩니다.

## 뉴스 중복 제거는 어떻게 동작하나요

`api/news.js`가 네이버·구글에서 각각 기사를 가져온 뒤, 제목을 단어 단위로 쪼개 비교해서
(어순이 달라도 알아볼 수 있도록) 비슷한 제목(유사도 40% 이상)은 하나로 합칩니다.
합쳐진 기사는 `NAVER+GOOGLE` 태그가 붙고, 링크는 네이버 기사 쪽을 우선으로 보여줍니다.

## 지수·환율 정보는 어디서 가져오나요

- 코스피/코스닥: 네이버 금융이 자체적으로 쓰는 실시간 폴링 API (`polling.finance.naver.com`)
- S&P500/나스닥/다우존스: 야후 파이낸스 공개 차트 API (15~20분 지연)
- 환율: 네이버 환율계산기 위젯이 쓰는 공개 JSON

출처가 페이지 구조를 바꾸면 해당 항목만 "불러오지 못했어요"로 표시되고 나머지 기능은 정상 작동합니다.
이런 문구가 보이면 알려주세요, 바로 맞춰드릴게요.

## 실시간 차트를 더 정확하게 만들고 싶다면

지금은 무료·키 불필요 범위에서 가장 정확한 방법(코스피/코스닥 실시간 + 해외지수 15~20분 지연)을 쓰고 있어요.
해외 지수까지 완전히 실시간으로 보려면 한국투자증권/키움증권 같은 증권사의 **OpenAPI**를 쓰는 방법이 있는데,
이건 직접 그 증권사에 계좌가 있어야 하고 API 키 발급 절차가 필요해서 지금은 적용하지 않았어요.
나중에 필요하시면 말씀해주세요, 그 방향으로 안내해드릴게요.

## 로컬에서 미리 보고 싶을 때

```bash
npm install -g vercel
npm install
vercel dev
```

`.env.local` 파일에 네이버 키를 넣어두면 로컬에서도 뉴스 API가 동작합니다.
