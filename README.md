# 경제 뉴스 시세판 (v2 — 앱 버전)

네이버 뉴스 API + 구글 뉴스(RSS)를 합쳐서 중복을 제거해 보여주고,
네이버 금융에서 주요 환율(미국·일본·태국·유럽·중국)을 가져와 상단 티커로 보여주는 대시보드입니다.
PWA로 만들어져 있어서 폰 홈 화면에 설치하면 앱처럼 열립니다.

## 이전 버전과 달라진 점

- **디자인 전면 교체**: 짙은 네이비 + 글래스모피즘 카드 스타일
- **뉴스 중복 제거**: 네이버·구글에 똑같이 뜬 기사는 하나로 합쳐서 `NAVER+GOOGLE` 태그로 표시
- **환율 티커 추가**: 상단에 가로 스크롤 환율 카드 (`api/fx.js`, 네이버 금융 스크래핑)
- **자동 새로고침**: 2분마다 자동으로 최신 뉴스/환율 갱신 (헤더 아래 진행 바로 표시)
- **PWA 지원**: `manifest.json` + `sw.js` + `icons/` — 홈 화면에 추가하면 앱처럼 실행
- **카테고리 관리 UI 변경**: 사이드바 대신 상단 가로 스크롤 칩 + 바텀시트(☰ 버튼)

## 배포 방법 (Vercel)

1. 이 폴더 전체(파일/폴더 구조 그대로, `index.html`이 맨 위에 오도록)를 GitHub 저장소에 올립니다.
2. https://vercel.com 에서 New Project → 저장소 선택 → Framework Preset은 "Other" 그대로 둡니다.
3. **Environment Variables**에 아래 두 개를 추가합니다. (네이버 개발자센터에서 발급받은 값, 이전과 동일)
   - `NAVER_CLIENT_ID`
   - `NAVER_CLIENT_SECRET`
4. Deploy 클릭.

환율 API(`api/fx.js`)는 별도 키가 필요 없습니다 (네이버 금융 공개 페이지를 그대로 가져와요).

## 올려야 하는 파일 목록

## 폰에 앱처럼 설치하기

- **안드로이드(크롬)**: 접속하면 하단에 "추가" 배너가 뜹니다. 누르면 바로 설치돼요.
- **아이폰(사파리)**: 공유 버튼(네모+화살표) → "홈 화면에 추가"를 누르면 설치됩니다. (iOS는 자동 배너를 지원하지 않아서, 접속하면 화면에 안내 문구가 떠요)

설치하면 완슐랭처럼 주소창 없이 앱 아이콘으로 바로 열립니다.

## 카테고리 추가/수정/삭제

헤더 오른쪽 **☰** 버튼을 누르면 바텀시트가 열립니다.
- 목록에서 **수정/삭제** 가능
- 아래 입력창에 이름+검색어 넣고 **추가하기**

카테고리는 브라우저(localStorage)에 저장돼서, 같은 기기·같은 브라우저에서는 유지됩니다.
다른 PC/폰에서는 기본 카테고리(국내증시/해외증시/금리/부동산)로 시작하고, 거기서 다시 추가하면 됩니다.

## 뉴스 중복 제거는 어떻게 동작하나요

`api/news.js`가 네이버·구글에서 각각 기사를 가져온 뒤, 제목을 2글자 단위로 쪼개 유사도를 비교해서
비슷한 제목(유사도 55% 이상)은 하나로 합칩니다. 합쳐진 기사는 카드에 `NAVER+GOOGLE` 태그가 붙고,
링크는 네이버 기사 쪽을 우선으로 보여줍니다.

## 환율 정보는 어디서 가져오나요

네이버 금융(`finance.naver.com/marketindex/exchangeList.naver`) 페이지를 서버에서 가져와 파싱합니다.
네이버가 페이지 구조를 바꾸면 파싱이 실패할 수 있는데, 그럴 땐 화면에 "환율 정보를 불러오지 못했어요"라고만
뜨고 나머지 기능(뉴스)은 정상 작동합니다. 이런 문구가 보이면 알려주세요, 구조를 다시 맞춰드릴게요.

## 로컬에서 미리 보고 싶을 때

```bash
npm install -g vercel
npm install
vercel dev
```

`.env.local` 파일에 네이버 키를 넣어두면 로컬에서도 뉴스 API가 동작합니다.
